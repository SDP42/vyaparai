# Licences: free and properly licensed only

**Rule:** the product uses only free software, data and assets with licences that allow our use, and nothing that needs a
paid plan, a hidden key or a licence we cannot meet. New dependencies are checked before they are added. A test
(`apps/api/tests/test_licenses.py`) reads the installed Python packages and the web lockfile and fails the build on GPL, AGPL, SSPL,
Commons Clause or proprietary terms, and on any unreviewed LGPL or custom licence.

_Audit of 2026-11-10: 87 Python packages and 173 web packages, read offline from package metadata and `package-lock.json`._

## Python (87)

MIT 48, Apache-2.0 14, BSD 17, ISC 2, PSF-2.0 1, MIT-0, 0BSD, Unlicense 1 each, and two MPL-2.0 packages (file-level copyleft; used unmodified,
so it does not reach our code). Notable: FastAPI, Pydantic, SQLAlchemy, Alembic, Uvicorn (BSD/MIT), **numpy and scipy (BSD)**, **LightGBM (MIT)**,
openpyxl (MIT), argon2 (MIT/Apache), PyJWT (MIT). Nothing is GPL or AGPL.

## Web (173)

MIT 105, Apache-2.0 16+, ISC 15, MPL-2.0 12 (Tailwind's CSS engine, unmodified), BSD-3 5, 0BSD 2, Zlib 1, CC-BY-4.0 1 (browser-support data; attribution only).
Notable: Next.js, React (MIT), Recharts (MIT), three.js and React Three Fiber (MIT), Motion (MIT), Lenis (MIT).

### Reviewed exceptions

| Package | Licence | Why it is acceptable |
|---|---|---|
| **gsap** (landing-page scroll animation) | GSAP "Standard no charge" licence: free, including commercial use; not OSI open source; forbids building tools that compete with GSAP's own visual animation products | We use it only for ordinary page animation. Revisit if the licence changes; Motion (MIT) is the fallback |
| **@img/sharp-\*** (14 packages) | LGPL-3.0-or-later (with Apache/MIT parts) | Optional native image libraries that Next.js installs for `next/image`. We do not use `next/image`, so they are not on our runtime path; they are separate, unmodified libraries, which LGPL allows. If we ship a container that includes them we keep their licence notices |
| MPL-2.0 packages | Mozilla Public Licence 2.0 | File-level copyleft; unmodified, so no obligations beyond keeping notices |

## How to check before adding a dependency

1. Read its licence field and its licence text. Permissive (MIT, BSD, Apache-2.0, ISC) is fine.
2. Refuse GPL, AGPL, SSPL, Commons Clause and anything that needs a key or a paid plan for our use.
3. Anything else (LGPL, custom, "no charge") needs a written reason in this file and an entry in the test.
